# ticker_Tape
Ticker Tape is a Streamlit financial dashboard for tracking global markets. Explore index charts, returns, business news and sector updates. Use AI-powered summaries and MarketBot to understand market movements, news and events. Supports light and dark themes, custom timeframes, OpenAI integration and Trading Economics economic data.
LIBRARIES: feedparser
          pandas
          plotly
          requests
          streamlit
          yfinance
          openai
